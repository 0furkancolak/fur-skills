# fur-ship Failure Modes

- Creating a branch, commit, push, or PR without explicit user approval.
- Leaving `Co-authored-by`, `Generated with`, model names, or agent attribution in commit messages or PR bodies.
- Creating a PR from `main` / `master` without a feature branch.
- Ignoring `.github` PR templates when creating a PR body.
- Fabricating PR URLs or branch state when `gh` is unavailable.
- Reporting readiness without running git/gh state checks.
